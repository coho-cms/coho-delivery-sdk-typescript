# create-coho

Creates your content library for Coho CMS: a TypeScript package, generated from your project's content types, that your sites and services install.

```bash
npm create coho@latest acme-content
```

**Not released yet.** This version prints a notice and exits. Follow [coho-delivery-sdk-typescript](https://github.com/coho-cms/coho-delivery-sdk-typescript) for the first release.
