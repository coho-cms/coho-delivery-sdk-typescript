# create-coho

Creates a TypeScript project for Coho CMS: typed content access generated from your project's content types.

```bash
npm create coho@latest my-site
```

**Not released yet.** This version prints a notice and exits. Follow [coho-delivery-sdk-typescript](https://github.com/coho-cms/coho-delivery-sdk-typescript) for the first release.
